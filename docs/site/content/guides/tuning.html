Start with the preset that matches the app's position source and power needs.

Presets

ConfigurationPresetUse when
standardThe app uses on-device positioning (default).
highAccuracyPositions must update quickly, at the cost of battery.
lowPowerBattery matters more than update rate.
relayOnlyPositions come from venue infrastructure through a relay; no beacon or native location.
 
const configuration = ProximiioConfiguration(
  token: token,
  preset: ConfigurationPreset.highAccuracy,
);

Overrides

Every field that is not null replaces the preset's value. Unset fields keep the preset.

final configuration = ProximiioConfiguration(
  token: token,
  preset: ConfigurationPreset.lowPower,
  apiBaseUrl: Uri.parse('https://api.proximi.fi'),
  geofenceExitDelay: const Duration(seconds: 5),
  visitorReportingEnabled: false,
);

With relayOnly on iOS, relayRunsInBackground: true keeps receiving relay positions in the background. On Android the foreground service does this.

Position update rate

With beacons, positions arrive at most once per bleEvaluationInterval, and only after the position moved enough to pass distanceFilter. Under the standard preset a walking visitor can wait several intervals for the next position. highAccuracy computes a position every second and fuses PDR, so each detected step publishes a position. The preset only turns on the fusion: PDR itself runs after enablePdr(), and it needs the motion permission. 

final configuration = ProximiioConfiguration(
  token: token,
  preset: ConfigurationPreset.highAccuracy,
  distanceFilter: const DistanceFilter(minimumDisplacement: 0.5),
);
// After authenticate() and start():
if (await sdk.requestMotionPermission()) {
  await sdk.enablePdr();
}

A shorter interval and a smaller filter use more battery and show more of the beacon signal's noise.

Applying changes

The configuration is read when the SDK instance is created. To change it, call Proximiio.create again with the new configuration; it stops and replaces the instance. Authenticate and start again afterwards.

Validation

Change one setting at a time and test it in the target venue. Compare diagnostics() before and after.
