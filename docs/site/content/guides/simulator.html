Simulators and emulators have no Bluetooth. The SDK can emit simulated positions through the normal positions stream, so geofences, floors and routes react as in the venue.

One position

await sdk.simulatePosition(const Coordinate(latitude: 24.4866, longitude: 54.6074), level: 1);

Walk a route

The SDK must be running.

await sdk.startSimulation(
  const SimulatedRoute(
    waypoints: [
      SimulatedWaypoint(Coordinate(latitude: 24.4866, longitude: 54.6074)),
      SimulatedWaypoint(Coordinate(latitude: 24.4869, longitude: 54.6079)),
      SimulatedWaypoint(Coordinate(latitude: 24.4871, longitude: 54.6081), level: 1),
    ],
    speed: 1.3,
    loops: true,
  ),
);
SettingDefaultPurpose
speed1.3 m/sWalking speed
updateInterval1 sTime between positions
loopsfalseStart over after the last waypoint
accuracy5 mReported accuracy

Control it with pauseSimulation, resumeSimulation, stopSimulation and jumpToWaypoint(index); read simulationState().

Simulation levels are whole numbers. Floors with intermediate levels cannot be simulated.

Keep it out of release builds

if (kDebugMode) {
  await sdk.startSimulation(route);
}
