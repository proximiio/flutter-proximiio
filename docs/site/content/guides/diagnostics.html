No position

noPositionReasonCheck
notStartedCall start.
noViablePositioningInputsLocation or Bluetooth is denied or off, or the venue has no beacons.
awaitingFirstFixStarted, no position yet. Wait, or check that the device is inside the venue.
privacyZonePositions are withheld inside a privacy zone.

Log level

await Proximiio.setLogLevel(ProximiioLogLevel.debug);

The native SDK writes to the platform log (Xcode console, Logcat). The level is process-wide. Use warning or error in release builds.

Support report

Record while reproducing a problem, then share the zip with Proximi.io support. Secrets are removed from the report.

await sdk.startDiagnosticsRecording();
// … reproduce the problem …
await sdk.stopDiagnosticsRecording();
final zipPath = await sdk.prepareDiagnosticsReport();

Errors

ProximiioException.underlying names the system error behind a failure, for example UnknownHostException: Unable to resolve host "api.proximi.fi". Log it with the code.
