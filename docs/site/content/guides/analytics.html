With visitor reporting on, the SDK registers an anonymous visitor and reports positions and geofence entries and exits to the Proximi.io analytics of the organisation.

Visitor reporting is on by default in SDK v6. If the app needs the visitor's consent for analytics, turn it off in the configuration and turn it on after consent.

Turn it off

const configuration = ProximiioConfiguration(token: token, visitorReportingEnabled: false);

Record consent

await sdk.setVisitorReportingConsent(userAgreed);
final granted = await sdk.visitorReportingConsent();

setVisitorReportingConsent(false) stops all reporting.

Visitor id

visitorId() returns the anonymous id used for analytics. resetVisitorId() replaces it with a new random id, for example when the visitor asks to be forgotten.
