Synchronisation

authenticate downloads the venue data and stores it on the device. While running, the SDK synchronises changes every syncInterval (5 minutes; 10 minutes with lowPower). sync() synchronises now and returns the number of changed records. 

sdk.syncEvents.listen((event) {
  switch (event) {
    case SyncCompleted(:final applied):
      print('sync: $applied changes');
    case SyncFailed(:final reason):
      print('sync failed, retrying later: $reason');
    case StoreRecreated(:final reason):
      print('store rebuilt: $reason');
    case SyncUpdated() || SyncDeleted():
      break;
  }
});

To refresh a screen, listen to venueDataChanges instead; see Data model.

Without a connection

Stored venue data stays available offline. start throws notAuthenticated until authenticate succeeds.

Without a connection, authenticate succeeds at once when the API accepted the token on this phone before (allowsOfflineStart, default true). tokenStatus() is then unverified: positioning runs on the stored data, nothing syncs or uploads, and the SDK checks the token when the connection returns. On a network that does not answer it gives up after 30 s. A token never accepted on this phone throws ProximiioErrorCode.api. On Android a bundled seed built for this token also lets it start offline.

A token the API keeps refusing for at least two hours (three checks) stops the SDK and deletes its local data, offline packages included. tokenStatus() is then rejected and syncEvents reports the failure.

Offline packages

An offline package holds a venue's data and map tiles for use without a connection.

final state = await sdk.syncOfflinePackage('terminal-1', allowsCellular: false);
switch (state) {
  case PackageReady(:final version):
    print('package version $version installed');
  case PackageFailed():
    print('sync failed; the previous version stays in use');
  default:
    break;
}
CallPurpose
offlinePackageState(id)PackageMissing, PackageDownloading, PackageReady, PackageStale, PackageVerifying, PackageFailed
installOfflineSeed(id, directory)Install from unpacked package files on disk, for example extracted from the app's assets on first launch
offlinePackageDiskUsage(id)Bytes on disk
removeOfflinePackage(id)Delete the package

Errors are ProximiioErrorCode.offlinePackage with kind (serverUnavailable, checksumMismatch, notInstalled, insufficientDiskSpace, …).
