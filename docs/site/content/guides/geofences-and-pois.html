Geofences are circles or polygons defined in the Proximi.io Portal. The SDK checks every position against them and reports entries and exits on geofenceEvents.

Entries and exits

sdk.geofenceEvents.listen((event) {
  switch (event) {
    case GeofenceEntered(:final geofence):
      showWelcome(geofence.name);
    case GeofenceExited(:final geofence, :final dwellTime):
      log('${geofence.name}: ${dwellTime.inSeconds} s');
    case PrivacyZoneEntered() || PrivacyZoneExited():
      break;
  }
});
  • An exit is reported geofenceExitDelay after the device leaves (default 3 s), so a short step outside does not end the visit.
  • dwellTime is measured by the SDK from the entry to the leave.
  • stop reports an exit for every geofence the device is in.

The geofences the device is in now: await sdk.enteredGeofenceIds().

Geometry

A circular geofence has area and radius (metres); a polygon has polygon and isPolygon. When the SDK could not read a geofence's stored geometry, geometryIssue says why (unreadableArea, degenerateOutline); fix the geofence in the Proximi.io Portal.

Privacy zones

Privacy zones are areas where the visitor's position must not be shown or reported. privacyZoneStateChanges reports whether the position is private now. 

sdk.privacyZoneStateChanges.listen((state) {
  hideDot = state.isPrivate;
});

With withholdsPositionsInPrivacyZones: true the SDK does not emit positions inside a privacy zone. isPrivate is also true when the positioning source marks the position private (setPositioningSourcePrivate).

Points of interest

POIs are GeoJSON features with properties.type poi. Their amenity links to an icon and a category. features() returns the features stored by loadRouteNetwork(); call it once after authenticate.

final amenities = {for (final a in await sdk.amenities()) a.id: a};
final pois = (await sdk.features()).where((f) => f.propertyType == 'poi');
for (final poi in pois) {
  final amenity = amenities[poi.properties?['amenity']];
  print('${poi.title()} (${amenity?.title}) on level ${poi.level}');
}
