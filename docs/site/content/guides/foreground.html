Foreground positioning runs the SDK while the app is visible and stops it when the app is paused. It needs only the when-in-use location permission and no background setup.

Follow the app lifecycle

class PositioningLifecycle with WidgetsBindingObserver {
  PositioningLifecycle(this.sdk) {
    WidgetsBinding.instance.addObserver(this);
  }

  final Proximiio sdk;

  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    switch (state) {
      case AppLifecycleState.resumed:
        unawaited(sdk.start());
      case AppLifecycleState.paused:
        unawaited(sdk.stop());
      default:
        break;
    }
  }

  void dispose() => WidgetsBinding.instance.removeObserver(this);
}

start while running and stop while stopped do nothing, so the observer needs no state of its own. Stream subscriptions stay valid across the cycle.

Configure

The default configuration does not keep positioning in the background:

final sdk = await Proximiio.create(const ProximiioConfiguration(token: token));

Without android: options the Android SDK runs no foreground service and shows no notification, and requestPermissions does not ask for the notification permission. allowsBackgroundLocationUpdates is false by default on iOS.

Verify

Send the app to the background: stateChanges reports authenticated. Bring it back: running.
