The SDK computes routes on the device from the venue's path network. It fetches the network, never a route. It draws nothing and does not reroute by itself: watch positions and compute again when the visitor leaves the route, or use the map plugin's guidance.

Load the path network

Install the network once after authenticate, before computing routes. start does not load it.

// Offline or cold start: install the stored copy at once, no request.
var paths = await sdk.loadCachedRouteNetwork();
try {
  // Online: download the features when they changed, store them, install the network.
  paths = await sdk.loadRouteNetwork();
} on ProximiioException catch (e) {
  // Keep routing on the stored network.
  log('route network refresh failed: ${e.code.name}');
}

Both return the number of routable paths; 0 means none are installed. The download is conditional, so calling loadRouteNetwork again costs one small request while the venue is unchanged. The features it stores are what features() returns. Sync keeps them current afterwards.

Compute a route

final route = await sdk.computeRoute(
  from: const Coordinate(latitude: 24.4866, longitude: 54.6074),
  fromLevel: 0,
  to: const Coordinate(latitude: 24.4871, longitude: 54.6081),
  toLevel: 2,
);
print('${route.distanceMeters.round()} m, about ${route.duration.inMinutes} min');

toLevel defaults to fromLevel. Levels are the level of the floors, not floor ids.

Accessibility

final route = await sdk.computeRoute(
  from: start, fromLevel: 0, to: goal, toLevel: 1,
  options: const RouteOptions(profile: RouteProfile.wheelchair, avoid: {RouteAvoidance.revolvingDoors}),
);
ProfileAvoids
pedestrianNothing (default)
wheelchairStaircases, escalators, narrow paths
strollerStaircases, escalators
staffNothing; reserved for staff-only paths

avoid adds to the profile: elevators, escalators, staircases, ramps, narrowPaths, hills, revolvingDoors, ticketGates, barriers.

The route

FieldMeaning
coordinatesThe route line
distanceMeters, durationLength and estimated time, level changes included
levelChangesOne LevelChange per ride (elevator, staircase, escalator, ramp)
instructionsTurn-by-turn RouteInstructions
estimatedArrival()Now plus duration
 
for (final step in route.instructions) {
  final text = switch (step.kind) {
    RouteInstructionKind.levelChange =>
      'Take the ${step.levelChange!.featureType} to level ${step.levelChange!.toLevel}',
    RouteInstructionKind.arrive => 'Arrive',
    _ => '${step.kind.name} in ${step.distanceMeters.round()} m',
  };
  print(text);
}

No route

computeRoute throws ProximiioErrorCode.noRoute with the reason:

noRouteReasonMeaningDetails
emptyNetworkNo path network (not drawn, or not loaded yet)
startOffNetworkThe start is too far from a pathnearestDistanceMeters
goalOffNetworkThe destination is too far from a pathnearestDistanceMeters
disconnectedThe paths of start and destination do not connect
noLevelTransitionNo level changer connects the levels
noAccessibleRouteEvery route uses something the options avoidblockedBy
 
try {
  route = await sdk.computeRoute(from: start, fromLevel: 0, to: goal, options: wheelchair);
} on ProximiioException catch (e) {
  if (e.noRouteReason != NoRouteReason.noAccessibleRoute) rethrow;
  showMessage('No step-free route. Blocked by: ${e.blockedBy.map((a) => a.name).join(', ')}');
}

Travel times

routeDurations returns the walking time between every pair of points, for sorting destinations by distance:

final matrix = await sdk.routeDurations([
  RoutePoint(here, level: 0),
  RoutePoint(cafe, level: 1),
  RoutePoint(exit, level: 0),
]);
final toCafe = matrix[0][1]; // null when there is no route
