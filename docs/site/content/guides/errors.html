Every method throws ProximiioException, and stream errors are ProximiioExceptions too. Switch on code; the other fields carry details. 

try {
  await sdk.authenticate();
} on ProximiioException catch (e) {
  if (e.isRetryable) {
    retryLater();
  } else {
    log('${e.code.name}: ${e.message} (${e.underlying})');
  }
}

Retrying

isRetryable is true for network and server failures. Retry them with a delay. Do not retry invalidToken; the token has to be replaced.

Stable identifiers

domain and failureCode are the SDK's stable identifiers (for example io.proximi.sdk / 1 for an invalid token). They are the same on iOS and Android and suit crash reporting and dashboards.
