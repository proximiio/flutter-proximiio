Start with diagnostics() and the code and underlying of the exception.

authenticate fails with api / network

authenticate validates the token with the API. kind: network means the device did not reach apiBaseUrl; underlying names the cause.

  • Check the device connection and that apiBaseUrl is the host of your installation.
  • A device in Doze blocks the network of apps in the background; an app started on a locked device cannot resolve hosts (UnknownHostException). Unlock the device.

features() is empty

Call loadRouteNetwork() once after authenticate; features() returns the features it stores.

Positioning stops in the background on Android

Without android: options in the configuration the SDK runs no foreground service. See Background positioning.

Android build: Failed to find Platform SDK with path: platforms;android-37

Use the Android Gradle Plugin 8.13 or newer and Gradle 8.13 or newer; see Installation.

Android build fails with a Java version such as 25.0.2

Gradle 8 cannot run on JDK 25, which recent Android Studio versions bundle. Point Flutter at JDK 17 or 21: flutter config --jdk-dir=<path>.

iOS app does not launch on iOS 27

iOS 27 requires the UIScene life cycle. Migrate the Flutter app's AppDelegate to UIScene as described in the Flutter documentation; the plugin needs no change.

iOS: pod 'Proximiio' not found

The pod is not on the CocoaPods trunk. Add the :podspec line from Installation to the Podfile.

Calls throw notConfigured

Call Proximiio.create before any other method.
