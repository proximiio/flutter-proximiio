6.0 moves the plugin from the Proximi.io SDK 5.x to SDK v6 and replaces the Dart API. Nothing of the 1.x API remains; this page maps each use.

Platform setup

  • iOS 15 and the Proximiio pod line in the Podfile. Remove pod 'Proximiio', '5.x'.
  • Android: minSdk 26, compileSdk 37, Android Gradle Plugin 8.13, Kotlin 2.2. Remove the old repositories maven.proximi.io/repository/android-releases, IndoorAtlas and Mapbox unless something else needs them.

See Installation.

Errors

1.x threw Exception('Failed to …'). 6.0 throws ProximiioException with a code; see Errors and failure handling.

Behaviour that changes

  • Visitor analytics are on by default. Set visitorReportingEnabled: false if the app has no consent.
  • A geofence exit is reported geofenceExitDelay (default 3 s) after the device leaves.
  • stop() reports an exit for every geofence the device is in.
  • On Android, positioning in the background needs android: options (the foreground service).
  • When the last Flutter engine is destroyed on Android, 1.x stopped the SDK. 6.0 stops it only when no foreground service is configured; with the service it keeps positioning, and the next engine reaches it with Proximiio.shared().
  • Positions inside privacy zones stay withheld, as in 1.x: the plugin sets withholdsPositionsInPrivacyZones: true, although the native v6 default is false.
  • ServiceNotificationMode.required behaves like enabled.
  • The iOS app needs all six usage descriptions in Info.plist; see Installation.
