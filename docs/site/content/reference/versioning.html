The plugin follows the SDK v6 line: 6.0.0-beta.N. Each release pins one iOS SDK and one Android SDK version and is tested with them. The release tag is the version (6.0.0-beta.1).

Native versions

flutter_proximiioiOS SDK (Proximiio)Android SDK (io.proximi.sdk:proximiio)
6.0.0-beta.16.0.0-beta.646.0.0-beta.31

On iOS with CocoaPods, the Podfile names the iOS SDK version; keep it equal to the table. With Swift Package Manager and on Android, the plugin pins the version itself.

Map

flutter_proximiio_map is released in lockstep and names the flutter_proximiio release it needs.

Changes

Every release is listed in the changelog. Breaking changes are marked BREAKING and link the migration notes.
