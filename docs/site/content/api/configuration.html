ProximiioConfiguration starts from a preset; every field that is not null overrides the preset. It is read when Proximiio.create runs.

Create a configuration

final configuration = ProximiioConfiguration(
  token: token,
  preset: ConfigurationPreset.standard,
  apiBaseUrl: Uri.parse('https://api.proximi.fi'),
  android: const AndroidServiceOptions(notificationTitle: 'Indoor navigation'),
);

DistanceFilter

The SDK publishes a position only after it moved at least max(minimumDisplacement, accuracyDisplacementFactor × accuracy) from the last published position. accuracy is the smaller horizontalAccuracy of the two positions. A stationary visitor gets no new positions. With PDR fusion, a detected step publishes a position without this check.

PropertyDefaultPurpose
minimumDisplacement1.33 mSmallest movement that publishes a position; at least 0
accuracyDisplacementFactor0.5Share of the accuracy the movement must also reach; at least 0

Validation

Proximiio.create throws invalidArgument for a URL that is not absolute, a UUID that does not parse, a bleEvaluationInterval that is not positive, or a DistanceFilter value that is negative or not finite. On iOS it also throws invalidArgument when Info.plist has no NSBluetoothAlwaysUsageDescription and the preset is not relayOnly.
