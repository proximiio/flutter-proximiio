Proximiio is the entry point. Proximiio.create makes the process-wide SDK instance; every method returns a Future and throws ProximiioException on failure. Proximiio is an interface, so tests can replace it with a fake. 

final Proximiio sdk = await Proximiio.create(const ProximiioConfiguration(token: token));
