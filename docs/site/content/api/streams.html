All streams are broadcast streams that stay open for the life of the app. They deliver events while the SDK runs (stateChanges and permissionUpdates also while stopped) and survive stop and start. A stream error is a ProximiioException. compassHeadings is the exception: it does not need the SDK to run (see Compass).

Compass

compassHeadings turns a position marker with the phone, also while the visitor stands still. pdrObservations gives the direction of walking instead, once per step and only while PDR runs.

  • Lifecycle. The compass runs while the stream has a listener and the app is in the foreground, whether the SDK runs or not. The first reading arrives a moment after the first listener.
  • Permissions. None. On iOS, with the location permission granted, the plugin also runs coarse location updates so Core Location can give true north.
  • North. degrees are from true north when isTrueNorth is true, else from magnetic north: on Android until the first position of a run, on iOS without the location permission.
  • Screen. 0° is the top of the screen in its current orientation.
  • Unreliable readings are skipped. When none arrive, the compass needs calibrating: the visitor moves the phone in a figure eight. A device without a compass delivers nothing.
// A Proximi.io wayfinding web app in a WebView turns its position marker with SET_HEADING.
sdk.compassHeadings.listen((heading) {
  controller.runJavaScript(
    "window.postMessage({type: 'SET_HEADING', heading: ${heading.degrees}}, '*')",
  );
});

Sealed events

GeofenceEvent, SyncEvent and BeaconEvent are sealed classes. A switch over them is exhaustive:

final text = switch (event) {
  GeofenceEntered(:final geofence) => 'in ${geofence.name}',
  GeofenceExited(:final geofence, :final dwellTime) => 'left ${geofence.name} after $dwellTime',
  PrivacyZoneEntered(:final zone) => 'private: ${zone.name}',
  PrivacyZoneExited(:final zone) => 'public again: ${zone.name}',
};

In widgets

StreamBuilder<PositionUpdate>(
  stream: sdk.positions,
  builder: (context, snapshot) => Text(snapshot.data?.coordinate.toString() ?? 'Locating…'),
)

Events emitted before a listener subscribes are not replayed. Seed the widget with lastPosition() if it needs a value at once.
