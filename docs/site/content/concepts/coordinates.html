Coordinates

Coordinate has latitude and longitude in degrees, WGS 84. Geofence and privacy-zone outlines (polygon) are lists of Coordinates.

GeoJSON lists positions as [longitude, latitude]. Feature geometry keeps the GeoJSON order; Coordinate and polygon are already converted.

Floors

ProximiioFloor.level is a double. Venues can have intermediate levels such as 0.5. Compare levels with == only when both come from the SDK.

WhereFloor information
PositionUpdate.floorThe floor of the position, when known
FloorChangeEventpreviousFloor, floor, direction, source (barometer, beacon, manual)
ProximiioGeofence.floorIdThe floor of the geofence
computeRoute(fromLevel:, toLevel:)Levels, not floor ids
SimulatedWaypoint.levelWhole levels only (int)

Floor changes

sdk.floorChanges.listen((change) {
  print('${change.previousFloor?.name} → ${change.floor?.name} (${change.source.name})');
});

To set the floor yourself, for example from a floor picker, call setFloor(floorId). The change is reported with source: manual.
