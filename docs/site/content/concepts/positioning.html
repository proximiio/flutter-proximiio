The SDK combines the available sources into one stream of positions. Each PositionUpdate names the source that produced it.

Sources

Custom positions

Set a position from an outside source, for example a scanned QR code at a known spot:

await sdk.setCustomPosition(
  const Coordinate(latitude: 48.1486, longitude: 17.1077),
  accuracy: 2,
  floorId: groundFloor.id,
);

floorId must be the id of a floor from floors(); an unknown id throws invalidArgument. Without floorId the position keeps the current floor. To set only the floor, use setFloor(floorId).

Pedestrian dead reckoning

PDR uses the motion sensors to keep the position steady between beacon updates. It needs the motion permission. 

if (await sdk.requestMotionPermission()) {
  await sdk.enablePdr();
}

To fuse PDR from the start, set pdrFusionEnabled: true in the configuration.

Route snapping

enableRouteSnapping moves positions onto the venue's paths when they are within the threshold (SDK default 5 m). It needs the route network; install it with loadRouteNetwork() first (see Wayfinding).

await sdk.enableRouteSnapping(thresholdMeters: 4);

No position

When no position arrives, diagnostics() reports why in noPositionReason (notStarted, noViablePositioningInputs, awaitingFirstFix, …). See Diagnostics and logging.
