Metadata

Custom metadata set in the Portal is decoded JSON in metadata: a Map, List, String, num or bool. Feature geometry and properties are decoded GeoJSON maps.

Feature titles

final pois = (await sdk.features()).where((f) => f.propertyType == 'poi');
for (final poi in pois) {
  print(poi.title('sk')); // Slovak title, else properties.title
}

Keeping a screen current

venueDataChanges reports which kinds changed. Re-read only those. A kind is reported only when its whole collection is stored, so a re-read never sees half an update. 

sdk.venueDataChanges.listen((change) async {
  if (change.contains(VenueDataKind.features)) {
    pois = await sdk.features();
  }
});
