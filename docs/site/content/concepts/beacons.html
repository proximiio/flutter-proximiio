The SDK scans for the beacons registered in the venue data, plus the iBeacon UUIDs in customIBeaconUuids. beaconEvents reports them while the SDK runs.

Identifiers

ClassFields
IBeaconIdentifieruuid (upper case), major, minor
EddystoneIdentifiernamespace, instance (hex)
UwbAccessoryIdentifiername

Events

sdk.beaconEvents.listen((event) {
  switch (event) {
    case BeaconFound(:final observation):
      print('found ${observation.identifier}, rssi ${observation.rssi}');
    case BeaconUpdated():
      break;
    case BeaconLost(:final identifier):
      print('lost $identifier');
    case BeaconTelemetryReceived(:final identifier, :final telemetry):
      print('$identifier battery ${telemetry.batteryMillivolts} mV');
  }
});

A BeaconObservation has rssi (dBm), txPower (dBm), timestamp and, for calibrated beacons, calibratedDistance in metres. Telemetry comes from Eddystone TLM frames.

Custom UUIDs

const configuration = ProximiioConfiguration(
  token: token,
  customIBeaconUuids: ['F7826DA6-4FA2-4E98-8024-BC5B71E0893E'],
);

Register the beacons in the Proximi.io Portal to use them for positioning.
