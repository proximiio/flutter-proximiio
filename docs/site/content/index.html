Proximi.io Flutter SDK v6

Indoor positioning, geofencing and wayfinding for Flutter apps on iOS and Android.

flutter_proximiio is a typed bridge over the native Proximi.io SDK v6 for iOS and Android. It exposes the same positions, floors, geofences, privacy zones, venue data and routes as the native SDKs, with the same names, as Dart Futures and Streams.

Install the plugin Quick start
Installation Add the package, the iOS pod line, the Info.plist keys and the Android build settings. Quick start Create the SDK, ask for permissions, authenticate, start, then listen to positions. Permissions What requestPermissions asks for on each platform. Architecture One native SDK instance per process, shared with the map plugin. Wayfinding Routes on the device, accessibility profiles and turn-by-turn instructions. API reference The Proximiio class, the configuration, the streams and the models.

The shortest integration

import 'package:flutter_proximiio/flutter_proximiio.dart';

final sdk = await Proximiio.create(const ProximiioConfiguration(token: 'YOUR_TOKEN'));
await sdk.requestPermissions();
await sdk.authenticate();
await sdk.start();

sdk.positions.listen((position) {
  print('${position.coordinate} on floor ${position.floor?.level}');
});

The first position arrives after the SDK has read the venue data and seen enough beacons or a native location fix. The quick start adds error handling and stopping.
